# Golazo 3D

Juego de fútbol 6 contra 6 en 3D que corre en el navegador con [Three.js](https://threejs.org). Todo está en un único `index.html`, sin compilación.

## Controles

| Tecla | Acción |
|---|---|
| WASD / flechas | Mover al jugador |
| Shift | Sprint (gasta resistencia) |
| Espacio | Disparar (mantén para más fuerza, suelta para tirar) |
| F | Pase al compañero |
| Enter | Jugar otra vez al terminar el partido |

El control pasa solo al jugador de Mar FC más cercano al balón. Tu equipo ataca hacia la derecha. El partido dura 2:30.

## Publicar en GitHub Pages

1. Sube `index.html` y este `README.md` a un repositorio.
2. En **Settings → Pages** elige la rama `main` y la carpeta `/ (root)`.
3. Abre `https://TU-USUARIO.github.io/NOMBRE-DEL-REPO/`.

Requiere conexión para cargar Three.js y las fuentes desde CDN.
